# 収益機会候補

> 分野候補の履歴です。現在の探索ルールは [判断OS](REVENUE_DECISION_FRAMEWORK.md)、作業順は [NEXT_TASKS](NEXT_TASKS.md) を参照。

以下はサイトテーマとの適合候補であり、提携可否・報酬・Cookie期間を示すものではありません。未確認値はサービス台帳で `null` / `unknown` とします。

| 分野 | コンテンツ導線 | 確認すべきこと |
| --- | --- | --- |
| AIコーディング | 比較、導入ガイド、料金計算 | 公式の提携窓口、規約、対象地域 |
| 画像・動画AI | 用途別比較、制作ワークフロー | 商用利用条件、アフィリエイト可否 |
| AI文章・翻訳 | 業務別診断、品質比較 | 無料版と有料版の表記、広告表示 |
| 議事録・業務AI | 導入比較、セキュリティ解説 | 法人向け紹介制度、個人情報の扱い |
| デザイン・クリエイター | 作品制作ガイド | 商標利用・ブランド表記ルール |
| 学習・リスキリング | 初心者向け選び方 | 受講効果の根拠、景品表示法上の表現 |

登録、提携申請、外部リンクの有効化、SNS投稿はいずれも人の確認と明示的な承認後に行います。
