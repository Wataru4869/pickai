# aierabi 全面UX/UI・情報設計改修 — 2026-09-15

## 1. 目的と結論

初訪問者がサービス名やモデル名を知らなくても、`用途 → 候補 → 比較 → 料金・注意点 → 自分で試す` の順で進める構造へ変更した。海外SaaS風の装飾やランキング訴求ではなく、日本語の可読性、判断順序、公式根拠への到達を優先した。

## 2. 情報設計

- ナビゲーションを「はじめる / 比較する / 目的から探す / 知る / 信頼情報」に再編。
- トップの主導線を「用途からAIを選ぶ」1つに絞り、「3つの質問で候補を確認」を補助導線にした。
- 用途は文章・資料、調査・検索、画像、動画、コーディング、自動化・AIエージェントの6入口。
- 主要AIカードは名前だけでなく、分類、扱う作業、候補にしやすい人、無料条件、公式情報確認日、詳細・比較への導線を表示。
- 個別AIは概要と向く作業を仕様一覧より前に表示。比較ページは「まず結論」と3つの比較項目を表より前に表示。
- Current Factsと2026年3月のHistorical Testsを視覚・導線ともに分離。

## 3. デザインシステム

- 日本語フォントを `Noto Sans JP / Hiragino Sans / Hiragino Kaku Gothic ProN / Yu Gothic / Meiryo / sans-serif` に統一。外部フォント通信は追加していない。
- 本文16px・行間1.75を基準に、見出し、カード、バッジ、CTA、セクション、フォーカス表示を共通化。
- 白・生成りを基調に濃紺緑を主色、橙をキーボードフォーカスに限定。ネオン、グラス表現、過剰なグラデーション、装飾アニメーションは不使用。
- desktopは236pxの目的別サイドバー、tablet/mobileはハンバーガーメニュー。44px以上の操作領域、Escでのメニュー終了、現在ページ表示を実装。

## 4. 主要ページ

- `/`: 旧ランキング中心ではなく、用途選択、主要5候補、3つの比較組合せ、料金、ガイド、詳細絞り込みの順へ全面再構成。
- `/categories`: 6用途それぞれに成果物、確認点、掲載候補を表示。
- `/categories/writing`: 文章・資料作成の新しい正規入口。既存の9月確認済みfactsだけを使用。
- `/model/*`: 一言概要、用途、候補にしやすい人、先に見る条件、CTA、公式facts、次行動の順へ変更。
- `/compare`・`/compare/*`: 用途による選び分け、3確認項目、組合せ選択、公式facts、実作業での確認の順へ変更。
- `/cost`: 月額だけで決めない4確認項目を追加し、公式料金・無料条件より前に提示。
- `/recommend`: 選定ルール・UTM伝播・CTAロジックは変更せず、branch上で見出しと選択肢の可読性・タップ領域のみ改善。
- `/blog/*`: 過去記事の警告ロジックを維持し、汎用記事の見出しと本文幅を日本語向けに改善。再確認済み記事の英語装飾ラベルを日本語化。
