# Update candidates

Automated collection may write proposals here, but must never edit public site data. Candidate status starts as `draft` or `blocked`. Only a human may set `approved`; a later, separate command may turn approved candidates into a reviewable patch.

Allowed objective fields are `service_name`, `provider`, `pricing`, `latest_model`, `features`, `availability`, and `official_url`. Rankings and evaluation scores are deliberately rejected by the validator.
