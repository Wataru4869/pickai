# Evaluation runs

Independent assessments live here, separately from official product facts. Each run gets a directory named with a stable run ID and a `manifest.json`. Raw prompts and outputs must be retained before any score is calculated.

Required manifest concepts: run ID, model/version, execution time, test IDs, evaluator type (`human` or `ai`), rubric version, raw evidence paths, and review status. Existing scores without these records remain historical and must not be rewritten by automation.
